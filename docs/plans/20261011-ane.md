# Neural Engine backend

Not scheduled. An opt-in macOS backend that runs the encoder of the Conformer families (Parakeet,
then GigaAM) on the Apple Neural Engine through Core ML; Whisper stays on the GPU, where the ANE
was slower ([other engines](20261010-other-engines.md)). On the M2 FluidAudio's ANE encoder made
Parakeet V3 2.2–2.3× faster than wavo on 11–35 s and its first transcript 190–250 instead of
250–480 ms; it also used a third of the energy, which matters less while the Mac is plugged in.
The GPU path stays the default and the only one with exact fixtures.

## Decisions

- **Model source.** Either an offline conversion script of our own (`scripts/`, coremltools,
  run with `uv`, never in the build) from the GGUF weights or the original checkpoint, publishing
  `.mlmodelc` to Hugging Face; or FluidInference's published Parakeet encoder (CC-BY-4.0:
  attribution in the readme and the model card, 6-bit palettized, their mel layout). GigaAM has no
  published Core ML model, so it needs the script either way. A pure-Rust MIL writer instead of
  Python costs ~1–1.5k lines more.
- **Window.** One fixed 15 s shape (ANE needs fixed shapes): short clips are padded, longer audio
  runs in overlapping windows with token merging, which slipped in FluidAudio and parakeet-mlx at
  joins. Alternative: enumerated shapes (e.g. 2, 5, 10, 15 s), each compiled on first use.
- **Correctness.** F16 activations (and palettized weights, if reused) can't match the fixtures
  exactly: agreement tests against the GPU path (word edits per clip, WER on the FLEURS clips)
  replace them for this backend only.
- **Compile.** The first Core ML load compiles for the ANE (16 s for Parakeet's encoder), cached
  by the OS per path and configuration: `pull` compiles once, so `run` never pays it.
- **Decoders.** Mel and the TDT / RNN-T loops stay on the CPU (wavo's NEON decoders); the joint's
  encoder projection goes into the Core ML graph or onto the CPU.
- **Binding.** `objc2-core-ml` (same `objc2` family as wgpu's Metal backend), behind a macOS-only
  feature; a model becomes a directory (`.mlmodelc` next to the GGUF) in `hub`.
