# Accuracy against the originals

Research for later, not scheduled. The fixtures check one link of a chain:

```
PyTorch original (F32)  →  transcribe.cpp (GGUF, Q8_0)  →  wavo (same GGUF)
```

`make test` proves the second arrow exact. A mistake in transcribe.cpp's port (preprocessing,
decoding, a tokenizer quirk) is copied into the fixtures and into wavo, and Q8_0's cost against
F32 is unmeasured. Known case: on `ru-long`, whisper-base gives "внутри нет конвертов" with the
reference's Metal build but "внутренне конвертов" with its Vulkan and CPU builds and with wavo's
portable path.

## Approach

- Ground truth: human transcripts from standard sets, small subsets (~200 clips each):
  LibriSpeech test-clean (English), FLEURS (Russian, Ukrainian, other European languages for
  Parakeet v3 and Whisper), Golos (Russian, GigaAM's own domain).
- Three implementations per model on the same 16 kHz mono clips:
  - the original: GigaAM's `gigaam` package, NVIDIA NeMo for Parakeet (or `parakeet-mlx` on a
    Mac), `openai-whisper` or HF `transformers` for Whisper;
  - transcribe.cpp at the pinned commit (`--batch`, as `make compare` runs it);
  - wavo (`examples/batch.rs`).
- Metrics: WER (and CER for Chinese) per model and set, text agreement between each pair, and
  the clips where they disagree, to see which side is closer to the truth.
- Tooling: one `scripts/` Python script run with `uv run` (PyTorch, NeMo and the datasets stay out
  of the library and its build), reusing `make compare` for the two GGUF engines. Heavy runs on
  the Windows RTX 4060 (CUDA for the originals), not on the person's Mac.
- Output: a table in `docs/perf.md`; any reference bug found is reported upstream, and a fixture
  changes only with the person's approval, backed by these numbers.
