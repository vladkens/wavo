# CPU backend

Encoders on the CPU for servers without a GPU, in pure Rust: f32 GEMM tiles with FMA (AVX2 on
x86_64, NEON on aarch64, portable otherwise) over weights kept Q8_0 and unpacked per panel, on all
threads. Target: GigaAM v3 e2e-rnnt at or under onnx-asr int8 (onnxruntime) on two N100 cores:
for 30 s of Russian a 6.1 s warm call, an 11.2 s first one, 0.55 GB. Text as on the GPU; log each attempt in `docs/perf.md`.

- [x] `Backend::Cpu` and `--backend cpu`; `auto` picks the CPU for GigaAM when the GPU wavo would
      pick is a software one (llvmpipe, lavapipe, WARP) or there is none.
- [x] GigaAM encoder on the CPU: subsampling, Conformer blocks with rotary attention, head; all
      GigaAM fixtures exact (`gigaam_*_cpu`).
- [x] N100 numbers on 2 and 4 cores against onnx-asr and faster-whisper small int8, with RSS.
- [x] Tune the tiles, job sizes and memory to the target.
- [x] Parakeet: relative attention on the CPU; all Parakeet fixtures exact (`parakeet_*_cpu`).
- [ ] Whisper.
