## Result

wgpu's Vulkan backend picks the RTX 4060 over the Radeon 610M iGPU. Neither offers 8×8 F32
cooperative matrices, so every kernel is the portable one. Measured after the x86 decoder and the
per-layer submissions (#12); per clip back to back, wavo `bench -n 20` and `transcribe-bench
--warmup 1 --iters 10` for the reference's CPU build (MSVC, AVX-512, scalar RNN-T decoder) and its
Vulkan build (NV_coopmat2), working set from a 10 ms `PeakWorkingSet64` poll. Cells are wavo /
reference CPU / reference Vulkan, ms (MiB for the peak); GigaAM on `jfk` and `dots` is timing only.

- All 7 models' fixtures exact, Whisper included, once the portable GEMM rounds W to f16 by hand.
- Against the reference's Vulkan build: GigaAM 5.3–12× faster (85–91% of the reference's time is
  its scalar decoder); Parakeet on par on `ru`, 12% slower on `jfk`, 1.3–1.5× on the long clips;
  Whisper 5.1× slower (its encoder 158 ms on cooperative matrices). Load 20–50% below; the weights
  sit in VRAM (415 / 801 / 1229 MiB).
- Against the run before the runtime AVX2 + FMA decoder: the default build 6–15× faster; `wavo
  run` on a 5-minute mp3 and a 10-minute m4a 2.1 / 7.0 s (were 16.3 / 46.1 s), text unchanged.
