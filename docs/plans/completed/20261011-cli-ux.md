# Easier first run

Done: 2026-10-11, PR #29, #31

From user feedback: a first-time user should get a transcript from `wavo talk.m4a` without
reading the help first. Two PRs: A + B (`feat/cli-ux`), then C (`feat/model-auto`), which adds one
method to the library's API (approved).

## Design

- **A. `wavo FILE`.** When the first argument isn't a command and is an existing file, `wavo FILE
  ...` is `wavo run FILE ...`. Commands win: a file named `list` needs `wavo run list`.
- **B. Download on `run`.** A model that isn't downloaded:
  - stdin and stderr are terminals (not stdout, so `wavo run x | fold` still asks): ask on stderr
    `<model> is not downloaded (<size>). Download it now? [Y/n]`. Enter, y or yes downloads with
    the usual progress, through `wavo::hub`, and transcribes; anything else, EOF or Ctrl-D fails
    with today's error and its `wavo pull` hint.
  - `-y` / `--yes` downloads without asking, also off a terminal: the opt-in for scripts.
  - otherwise unchanged: fail with the `wavo pull` hint, never download unasked.
  - The audio file must exist before anything is asked or downloaded. `bench` never downloads.
- **C. `--model auto`.**
  - Library: `Model::languages(&pcm)` ranks the languages Whisper hears on the first 30 s
    window (the same logits `transcribe` picks from) with their probabilities, empty for models
    without language ID; a `#[non_exhaustive]` `Language`, rustdoc with an example. All of them,
    not only the first, so the CLI can weigh in the prior.
  - CLI: load `whisper-tiny` (downloaded as in B), detect, map the language in one small table
    (ru → `gigaam-v3`; en and the other languages `parakeet-v3` covers → `parakeet-v3`; else
    `whisper-turbo`), print `detected <lang> (<p>) → <model>` on stderr and transcribe with that
    model (downloaded as in B).
  - System-language prior: macOS preferred languages and keyboard input sources, Linux
    `LANGUAGE` / `LANG`, Windows preferred UI languages if cheap without a dependency, else
    `LANG`. Detection favours those plus English by a weight chosen from data, so another
    language wins only when Whisper is far surer of it.
  - Measure first: whisper-tiny and whisper-base language ID on `3rd/transcribe.cpp/samples/`
    and their 2–3 s cuts, with and without the prior. The default for `wavo run` without a model
    stays `parakeet-v3`; making it `auto` is the person's call, proposed with the numbers.

## Result

Language ID on the 30 reference samples with a known language (en, ru, uk, de, ar, ja, ko, vi,
zh; `yue` counted as zh, tiny and base have no `yue`), their first 30 s and every 2 s and 3 s cut
of it, skipping cuts under a quarter of the clip's RMS (silence). "Model" counts picking the
right model even when the language is wrong (uk taken for ru is a wrong model; de for en is
not). The prior is the spoken language plus English ("own"), or English plus Russian (Ukrainian
for Russian clips) for a speaker of other languages ("foreign"); own languages weigh ×30.

| | 30 s (30) | 3 s cuts (172) | 2 s cuts (263) |
|---|---|---|---|
| tiny, no prior: language / model | 93% / 93% | 85% / 90% | 80% / 88% |
| tiny, prior ×30, own | 100% / 100% | 91% / 94% | 86% / 91% |
| tiny, prior ×30, foreign | 90% / 90% | 78% / 82% | 71% / 78% |
| base, no prior | 93% / 97% | 90% / 93% | 81% / 87% |
| base, prior ×30, own | 100% / 100% | 94% / 95% | 88% / 92% |
| base, prior ×30, foreign | 93% / 93% | 80% / 84% | 75% / 81% |

The most common error is uk taken for ru (14 of 53 errors on 2 s cuts for tiny); others are short
cuts of ar, vi and de taken for en. The first 30 s of jobs-silence come out as `nn`, Whisper's
usual answer for silence; the prior turns that into en. A hard threshold (another language only above p ≥ 0.8)
scored the same for own languages but picked an own language at p ≈ 0 for foreign speech;
the weight doesn't.

Cost on the RTX 4060, `wavo FILE` vs `wavo FILE --model auto`, 5 runs each, whole process:
jfk 559–694 vs 699–742 ms (parakeet-v3), ru-short 368–416 vs 547–555 ms (gigaam-v3): +0.15 s
for loading whisper-tiny and one window. Reading the system languages takes 14 ms on macOS.

Proposed: `auto` as the default for `wavo run` without a model, since a dictation-length clip in
the person's own language picks the right model 91–100% of the time, for +0.15 s. Kept
`parakeet-v3` as the default until the person decides.
